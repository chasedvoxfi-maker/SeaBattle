# 🚢 Морской бой

Красивый браузерный «Морской бой» с анимациями, звуками и тремя режимами игры:

- 🤖 **Против компьютера** — три уровня сложности (Новичок / Капитан / Адмирал). Компьютер сам скрытно расставляет флот и охотится за вашим по алгоритму «охота-добивание» (на «Адмирале» — с расчётом вероятностной плотности).
- 👥 **Два игрока за одним экраном** — с экраном «передайте устройство» между ходами, чтобы никто не подглядывал.
- 🌐 **Игра онлайн** — настоящий P2P-мультиплеер прямо в браузере (WebRTC), без собственного сервера: один игрок создаёт комнату и получает 4-значный код, второй вводит код и подключается напрямую.

Эффекты: горящая клетка при попадании (мерцающий огонь + дым), взрыв с частицами и «тряской» экрана при потоплении корабля, всплеск при промахе, салют и победная музыка на экране победы. Все звуки синтезируются на лету через Web Audio API — никаких внешних аудиофайлов не требуется.

## Как это устроено (онлайн-режим)

Раньше был свой WebSocket-сервер, который судил игру. Теперь онлайн работает как у типичных serverless P2P-игр: браузеры соединяются друг с другом напрямую через **WebRTC**, а для первичного «знакомства» (signaling) используется библиотека [Trystero](https://github.com/dmotz/trystero) через публичные BitTorrent-трекеры — бесплатно и без своего бэкенда. Код библиотеки (MIT-лицензия) лежит локально в `public/js/vendor/trystero/`, подключать ничего дополнительно не нужно.

Модель доверия: отдельного «судьи» больше нет — каждый игрок считает попадания по **своей собственной** доске и сообщает результат сопернику напрямую. Для игры с другом этого достаточно; против читерства это не защищает, но оно и не требовалось.

Из этого следует главный плюс: игра теперь **полностью статическая** (чистые HTML/CSS/JS), и её можно бесплатно разместить на GitHub Pages — сервер вообще не нужен.

## Запуск локально

```bash
npm install
npm start
```

Откройте [http://localhost:3000](http://localhost:3000). Порт можно сменить переменной `PORT`. Node-сервер здесь нужен только для удобной раздачи файлов во время разработки — к игровой логике он не имеет отношения.

Для локальной игры с другом по сети — оба открывают адрес вашего компьютера в локальной сети (например `http://192.168.x.x:3000`) и используют режим «Игра онлайн».

## Деплой на GitHub Pages

В репозитории уже есть workflow `.github/workflows/deploy-pages.yml`, который при каждом пуше публикует папку `public/` на GitHub Pages. Нужно один раз включить Pages в настройках:

> На бесплатном тарифе GitHub Pages работает только для **публичных** репозиториев — если репозиторий приватный, сначала сделайте его публичным (Settings → Danger Zone → Change repository visibility).

1. Зайдите в репозиторий → **Settings → Pages**.
2. В поле **Source** выберите **GitHub Actions** (не "Deploy from a branch").
3. Сделайте любой пуш в ветку — через минуту-полторы сайт появится по адресу вида `https://<ваш-аккаунт>.github.io/<репозиторий>/`.

Дальше можно открывать эту ссылку с любого телефона или компьютера — бесплатно, без «засыпания» и без ограничений по CPU/RAM, в отличие от бесплатных тарифов Render/Railway.

## Как добавить фоновое фото в главное меню

Положите картинку в `public/assets/menu-bg.jpg`, затем в файле `public/css/style.css` найдите блок `.menu-photo-bg` и пропишите путь:

```css
.menu-photo-bg {
  background-image: url('../assets/menu-bg.jpg');
  ...
}
```

Фон автоматически подстроится под тёмную морскую тему (лёгкое затемнение и наложение цвета).

## Структура проекта

```
server.js              — простой статический сервер для локальной разработки (express.static)
public/
  index.html            — разметка всех экранов игры
  assets/                — сюда кладётся фоновое фото меню
  css/style.css          — оформление и анимации (огонь, взрыв, всплеск, свечение)
  js/
    rules.js              — общая игровая логика (флот, расстановка, обработка выстрелов)
    board-render.js        — отрисовка игрового поля 10×10
    effects.js              — частицы (взрывы, салют), тряска экрана
    audio.js                 — звуковой движок на Web Audio API
    ai.js                     — искусственный интеллект компьютера
    network.js                 — P2P-клиент онлайн-режима (WebRTC через Trystero)
    main.js                     — сценарии всех трёх режимов игры
    vendor/trystero/             — вендоренная библиотека Trystero (MIT), без сборщика
```

## Правила

Классический флот: 1 линкор (4 клетки), 2 крейсера (3 клетки), 3 эсминца (2 клетки), 4 катера (1 клетка). Корабли нельзя ставить впритык друг к другу. Попадание даёт право на повторный выстрел, промах передаёт ход сопернику. Побеждает тот, кто первым потопит весь вражеский флот.
