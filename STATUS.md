# STATUS — Морской бой

## 2026-10-21, ветка claude/battleship-game-effects-w4l8vu

**Цель проекта:** браузерная игра «Морской бой» с красивыми эффектами (пожар/взрыв/всплеск), тремя режимами (с компьютером, хотсит, онлайн) и опубликованная на GitHub Pages.

**Сделано:**
- Полная игра на чистых HTML/CSS/JS без сборщика: `public/index.html`, `public/css/style.css`, `public/js/*.js`.
  - `public/js/rules.js` — общая игровая логика (флот, расстановка, обработка выстрелов).
  - `public/js/board-render.js` — рендер поля 10×10.
  - `public/js/effects.js` — частицы (взрывы, салют), тряска экрана.
  - `public/js/audio.js` — звуки на Web Audio API (без внешних файлов).
  - `public/js/ai.js` — ИИ компьютера (hunt/target, с вероятностной плотностью на сложности «Адмирал»).
  - `public/js/network.js` — P2P-клиент онлайн-режима поверх WebRTC.
  - `public/js/main.js` — главный контроллер всех трёх режимов и UI-состояний.
- Онлайн-режим переведён с WebSocket-сервера на **чистый P2P через WebRTC** (библиотека Trystero, вендорена локально в `public/js/vendor/trystero/`, MIT-лицензия, без сборщика). Комнаты находят друг друга через публичные BitTorrent-трекеры. Сервер-судья больше не нужен — каждый игрок считает попадания по своей доске и шлёт результат напрямую сопернику.
- `server.js` упрощён до простой раздачи статики (`express.static`) — нужен только для локальной разработки (`npm start` → localhost:3000), к логике игры отношения не имеет.
- `shared/rules.js` и зависимость `ws` удалены как ненужные после перехода на P2P.
- Добавлен `.github/workflows/deploy-pages.yml` — автодеплой папки `public/` на GitHub Pages при пуше.
- **Репозиторий сделан публичным** и **GitHub Pages включён** (Settings → Pages → Source: GitHub Actions) — это ручной шаг, который мог сделать только владелец репозитория, не я.
- Проверено (Playwright, headless Chromium):
  - Режим «с компьютером»: полная партия до победы, скриншоты ОК, ошибок в консоли нет.
  - Хотсит: расстановка обоих игроков, экран «передайте устройство», бой, пас при промахе — всё работает.
  - Онлайн P2P: прогнан настоящий сквозной тест с локальным self-hosted relay (`@trystero-p2p/ws-relay`, временно, не закоммичено) — два независимых браузерных контекста реально соединились по WebRTC, сыграли полную партию до победы/поражения, порядок хода и все эффекты синхронизировались верно.
  - Финальный деплой на GitHub Pages: workflow run `38670363066` завершился `conclusion: success`, лог показывает `Reported success!` и URL `https://chasedvoxfi-maker.github.io/SeaBattle/`.
